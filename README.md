# Student Helpdesk Ticket Management System

## About the Project
A beginner-level Java console application for managing student support tickets. It allows users to create, search, update, and resolve support tickets.

## Features
- Create tickets with unique ticket IDs
- Store student details and issue descriptions
- Categorize tickets
- Assign ticket priorities: Low, Medium, and High
- View and search tickets
- Update open tickets
- Resolve tickets and track status
- Validate user input

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList and Java Collections
- Enums
- Console-based interface

## How to Run
1. Install the Java Development Kit (JDK).
2. Open a terminal in the project folder.
3. Compile the program:

   `javac Main.java`

4. Run the program:

   `java Main`

## Current Limitations
- Ticket data is stored in memory and resets when the application closes.
- The application uses a console interface.
- No database is connected yet.

## Learning Objectives
This project demonstrates Java fundamentals, classes, objects, encapsulation, collections, loops, conditional statements, input validation, and basic object-oriented design.
